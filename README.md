# Realms of Legacy — Character Builder

A step-by-step character creation wizard for the Realms of Legacy TTRPG.

## Features

- 10-step guided character creation
- All game data embedded (Lineages, Classes, Specialties, Lifepath)
- Auto-calculates HP, MP, Sorce Points
- Exports directly to the official form-fillable PDF
- Save/load progress as JSON
- Works fully offline — no server required
